# Castorice 独立情绪过渡设计

## 目标

为 Castorice 的 Happy、Shy、Sleepy、Surprised、Pouting、Confused、Proud、Crying 八种情绪制作独立的待机到情绪过渡。现有待机分层作为动作生成的共同起点和约束，现有完整情绪 PNG 作为各自不可修改的最终状态。

情绪停留阶段继续显示现有静态情绪 PNG。情绪结束后倒放该情绪的入场序列返回待机，不单独保存退场 PNG。

## 素材边界

- 共用 `Assets/Skins/Castorice/layers/manual` 下的八个待机图层：后发、躯干裙子、画面左右腿、画面左右臂、脸、刘海。
- 不为八种情绪重新分层。
- 每张现有情绪 PNG 是独立完整图像，只作为对应情绪的最终目标和视觉参考。
- 不重新绘制情绪终态，不使用 AI 光流插帧，不制作情绪停留循环。

## 单个情绪序列

每个情绪拥有约 6 帧、总时长约 350 ms 的独立入场序列：

1. 首帧匹配标准待机姿态。
2. 中间帧利用待机分层的 pivot、位移、旋转、缩放和透明度逐渐接近目标姿态。
3. 完整情绪目标图作为最上层逐步淡入，待机分层同步淡出。
4. 末帧必须与现有完整情绪 PNG 完全一致。
5. 情绪显示约 2 秒后，主程序倒序播放同一组帧并恢复待机动画。

具体帧数和间隔允许按情绪微调，但同一情绪内必须使用固定间隔。

## 八种动作方向

- Happy：身体上提，双臂向胸前收拢，头发延迟跟随，末段轻微回弹。
- Shy：身体下沉并内缩，双臂合到身前，头部略低，整体柔缓。
- Sleepy：头部与躯干缓慢下沉，手臂放松，头发延迟落下，不回弹。
- Surprised：先轻微压缩，再快速上提，双臂向外张开，头发最后跟上。
- Pouting：身体轻微前移，手臂转向叉腰姿态，动作短促并快速稳定。
- Confused：头部和上身逐渐倾斜，双手抬到胸前，头发反方向延迟。
- Proud：躯干上提并展开，双臂抬起，末段轻微上扬回弹。
- Crying：肩部内收、身体下沉、双手抬向脸部，末两帧带极小幅颤动。

## 源数据与运行时资源

源数据保留在 CastoPet：

```text
Assets/Skins/Castorice/
  layers/manual/
  expressions/targets/Happy.png
  actions/expressions/happy.transition.animator.json
```

编辑器生成并写回运行时目录：

```text
Assets/Runtime/Castorice/Expressions/
  Castorice.Expression.Happy.png
  Happy/Transition/
    Castorice.Expression.Happy.Transition.00.png
    ...
    Castorice.Expression.Happy.Transition.05.png
```

退场只反向读取 `Transition` 中的入场帧，不生成单独的 Out 目录。

## 编辑器与 CLI

CastoPetAnimator 增加“情绪过渡”动作分类，并能选择八种情绪中的任意一种进行编辑、预览和保存。动作工程包含八个共用待机图层以及一个对应的完整情绪目标图层。

CLI 支持：

- 从 CastoPet 扫描八种情绪及其源工程。
- 创建或更新情绪过渡工程。
- 单独渲染一个情绪。
- 批量渲染并写回全部情绪。
- 写回前校验并备份旧运行时资源。

渲染器必须补齐绕 pivot 的旋转和缩放，并与网页预览使用相同的变换顺序和插值结果。

## 主程序数据模型与播放

`PetExpressionDefinition` 从“名称和单张 PNG”扩展为：

- 情绪 ID 和显示名称。
- 最终静态 PNG 路径。
- 专属入场帧路径列表。
- 专属帧间隔。

选择情绪时，主程序播放该情绪的专属帧列表，随后显示最终静态 PNG 并启动现有约 2 秒计时。计时结束后倒序播放同一列表，再恢复普通待机动画。

皮肤清单继续兼容旧的单张情绪 PNG 格式。旧皮肤或缺失专属帧的情绪回退到现有通用表情过渡；若通用过渡也缺失，则直接切换静态图。

## 校验与故障处理

- 每组过渡至少 2 帧。
- 所有帧必须是统一尺寸的透明 PNG，Castorice 内置资源要求为 320×320。
- 首帧必须匹配标准待机姿态，末帧必须与对应最终情绪 PNG 一致。
- CLI 在写回前完成全部校验；校验失败时不修改运行时目录。
- 写回采用临时目录和整体替换，并在 CastoPetAnimator 工作区备份旧资源。
- 单个情绪资源缺失不能阻止其他情绪和桌宠主体启动。

## 测试与验收

- 渲染器通过像素级测试验证 pivot、旋转、缩放、透明度和组合顺序。
- 网页预览与 CLI 对相同工程、相同帧生成一致结果。
- 主程序测试每个情绪读取自己的过渡帧、正序入场和倒序退场。
- 皮肤清单加载与写出测试覆盖旧格式兼容和新格式往返。
- 项目测试验证所有新增 PNG 已作为 WPF 资源打包。
- 为八种情绪生成接触表，检查双影、跳位、透明边缘、头发穿插和肢体错位。
- 浏览器自动化验证情绪选择、播放、暂停、保存、批量渲染和写回流程。

## 实施边界

实施分为四个连续部分：先补齐编辑器渲染变换，再建立八个情绪工程并生成资源，然后扩展 CastoPet 表情数据模型与播放逻辑，最后完成网页联动、批量 CLI 和端到端验证。每部分都必须保持已有 idle、move、blink 和旧皮肤行为可用。
