# Generated Artifacts

This directory contains outputs that can be regenerated or retained locally for analysis.

- `builds/`: local build and packaging workspaces.
- `packages/`: generated installers and update packages.
- `reports/`: stability reports and archived task diagnostics.
- `generation/`: tracked generation workflow metadata plus ignored large run data.
- `temp/`: disposable intermediate files.

Application source and packaged runtime assets do not belong in this directory.
